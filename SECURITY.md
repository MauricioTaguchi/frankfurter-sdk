# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/MauricioTaguchi/frankfurter-sdk/security.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/MauricioTaguchi/frankfurter-sdk/issues

## Scope

This policy applies to the generated Maurício Taguchi SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Frankfurter SDK public API, generated by
Maurício Taguchi. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
